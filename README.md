# Playlist & Player UI Module
Developer: D.G.S. Piyaratne (22FIS0447)

---

## Overview
This module focuses on the development of the Playlist and Music Player user interface for the Emora, Emotion-Based Music Recommendation System. The UI is built using Flutter and designed in Figma before implementation.

---

## Objectives
- Design a modern and user-friendly music player interface.
- Ensure smooth navigation between playlist and player screens.
- Maintain responsive and consistent UI components.

---

## Implemented Screens

### 1. My Playlists Screen
- Displays user-created playlists.
- Includes playlist cards (cover image, title, number of songs).
- Floating action button to create new playlist.
- Mini player at bottom for quick access.

### 2. Playlist Details Screen
- Shows selected playlist information.
- Displays list of songs.
- Includes Play All and Shuffle options.

### 3. Now Playing Screen
- Displays current song details.
- Album cover image.
- Song title and artist name.
- Progress bar with duration.
- Playback controls (previous, play/pause, next).
- Shuffle, repeat, and like buttons.

### 4. Create Playlist Screen
- Input field for playlist name.
- Option to upload cover image.
- Save button.
